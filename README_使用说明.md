# VLA 面试练习室

一个在本机浏览器使用的 VLA / 具身智能面试学习工具。已经内置 84 条参考问答、168 道经过整理的单选与填空题，以及对应原题 Q82–Q101 的 20 道 Python / PyTorch 代码练习。答辩原文中包含技术图解、论文原图和出处链接。

## 在这台电脑上开始

1. 打开终端，进入本目录：

   ```bash
   cd /home/ubuntu/Documents/Codex/2026-11-10/new-chat/outputs/vla-practice
   ./start.sh
   ```

2. 在同一台电脑的浏览器打开 <http://127.0.0.1:8765>。保持终端运行；按 `Ctrl+C` 可停止服务。
3. 点「题库练习」作答，点「答辩原文」查看完整答案、图解及参考来源；点「手撕代码」使用编辑器、查看提示和运行测试。

学习记录保存在项目目录的 `.local/practice.sqlite`。在「学习统计」可导出完整 JSON 备份；恢复备份会替换当前题库和记录，请先备份。备份包括待审核草稿和历史题目版本。服务只监听本机地址。

## 代码题环境

代码测试使用 Docker 容器中的 Python 3.11 和 CPU 版 PyTorch，不需要在你的主 Python 环境中安装 PyTorch。本机镜像 `vla-practice-runner:1` 已构建，可直接运行。

在其他电脑上，需要先安装并启动 Docker，再在本目录运行：

```bash
./scripts/build-runner.sh
./start.sh
```

首次构建需要网络下载基础镜像和 PyTorch。代码执行关闭网络、使用只读根文件系统和非 root 用户，并设置运行时间、内存、进程和输出限制。如果 Docker 未启动，普通题库和代码编辑仍可使用，运行按钮会显示环境未就绪。此隔离环境适合本机练习，不应当作承载不可信第三方代码的公共判题服务。

## 导入自己的材料

在「导入材料」上传 Markdown、TXT、PDF、DOCX，或符合 `vla-bank-v1` 结构的 JSON。页面先展示识别结果，确认后才入库。普通文档会作为**来源材料**保存，不会未经验证地自动变成选择题；可以配置 AI 来生成待审核题，或者导入包含标准答案的结构化 JSON。扫描 PDF 需先 OCR；复杂公式、图片和表格需与原文核对。相同正文重复导入不会重复入库。

## 可选：AI 生成新题

内置题库无需模型或 API 密钥。新增材料若要自动生成题目：

1. 复制 `.env.practice.example` 为 `.env.practice`。
2. 填写 Ollama 地址和模型名，或 OpenAI 兼容接口地址、模型与密钥；重启 `./start.sh`。Ollama 模型需自行提前下载并启动。
3. 到「AI 生成」选择章节、题型和数量。每批最多 10 题，使用所选章节的前 20 条来源；生成后核查答案、干扰项与证据，再审核入库。

使用 Ollama 本地服务时材料留在本机；如果配置远程兼容接口，所选材料及出题提示会发送到你配置的服务商，请先确认可以共享。生成结果仅验证格式和证据是否存在，技术正确性、唯一性仍需人工审核。本机尚未配置模型，因此未对真实外部模型做联网生成测试。

## 首次安装和迁移

需要 Python 3.11 或更新版本。直接运行 `./start.sh` 会建立 `.venv` 并安装 `requirements-practice.lock` 中的后端依赖；若源码包没有已构建的 `web/out`，还需要 Node.js 和 npm，脚本会执行 `npm ci` 和前端构建。可通过 `VLA_PYTHON=/path/to/python ./start.sh` 指定 Python。首次安装依赖需要网络；现有这台电脑的环境已安装。

本程序构建于开源项目 `docs-to-quiz`，有关代码复用、许可和版本见 [THIRD_PARTY.md](THIRD_PARTY.md)。
